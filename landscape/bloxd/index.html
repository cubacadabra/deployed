Landscape / Main product comparison

Bloxd is more creator-relevant than it looks.

Bloxd has a documented JavaScript game API for world owners, covering players, entities, movement, messaging, and other gameplay mechanics.

The creator on-ramp

Let playing and making become the same activity as early as possible.

Bloxd is a competitor for players and beginning creators even though its visual language is Minecraft-like. Its relevant question is how easily an active player can turn a world into a custom game.

Do not confuse its public API documentation repository with an open-source release of the full platform. The API is the comparison point; the engine remains a separate question.
