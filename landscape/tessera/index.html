Landscape / Emerging engine

Tessera is unusually close to the technical direction.

Tessera is an early Roblox-style engine whose public materials describe Rust, wgpu, Luau-related compatibility, a visual editor, and standalone/headless runtime architecture.

High-priority technical watch

Track technical overlap without confusing an engine prototype with a player platform.

Tessera overlaps with cubacadabra’s implementation choices closely enough to merit attention for useful comparisons, possible collaboration, or competition for early contributors.

Its announcement calls it an open-source Roblox alternative, but a currently usable public source release and license were not independently established. Treat it as an early project, not a proven hosted replacement.
